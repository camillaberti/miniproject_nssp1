# Overview
This repository contains all the code files, together with the dataset and the images regarding the first Mini Project of NSSP. Specifically: 
- `utils.py` contains useful functions used in the notebooks
- `01_struct_preprocessing.ipynb` downloads the dataset and perform anatomical preprocessing.
- `02_func_preprocessing.ipynb` does the functional preprocessing
- `03_glm.ipynb` contains the GLM analysis
- `04_ica.ipynb` performs the independent component analysis
